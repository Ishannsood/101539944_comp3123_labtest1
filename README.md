# COMP3123 Lab Test 1

## Question 1: ES6 Features
Created a function named lowerCaseWords that returns a Promise, filters out non-string values, and converts strings to lowercase.

## Question 2: Promises
Created resolvedPromise and rejectedPromise functions that execute after a 500ms timeout and handle their results using then() and catch().

## Question 3: File Module
Created remove.js to remove files from the Logs directory and add.js to create the Logs directory and generate 10 log files.

## How to Run

Run the following commands from the project directory:

    node question1.js
    node question2.js
    node remove.js
    node add.js

## Requirements
Node.js
